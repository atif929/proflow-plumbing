# ProFlow Plumbing

CimpleTech demo website (fictional business). Next.js App Router, JavaScript/JSX, plain CSS.

```bash
npm install
npm run dev     # development
npm run build   # production build
```

Foundation (Iteration 2):
- Design tokens, reset, typography, `.container` / `.section` helpers: `app/globals.css`
- Lato (local, `app/fonts/`) via `next/font/local`
- `components/ui/Button.js` — `variant="primary" | "secondary"`, pass `href` for a link
- Breakpoints: 640px / 900px / 1200px (documented in `globals.css`)

Status: Iteration 2 complete.
